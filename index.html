3. Nivel y sensibilidad

-80 dB— dB0 dB
Umbral mínimo de volumen: dB

La línea blanca del medidor es el umbral. Por debajo de él se ignora el sonido (ruido de fondo). Toca una cuerda: la barra debe pasar claramente la línea.

Tolerancia de afinación: ± cents
Estabilidad requerida: ms

Tiempo que la nota debe mantenerse estable para aceptarla.

4. Afinador de prueba

Toca cada cuerda al aire para comprobar que se detecta y que está afinada.
